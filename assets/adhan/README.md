# أصوات الأذان

ضع ملف الصوت هنا بالاسم المحدد في `src/data/adhan-voices.js`، فيظهر تلقائياً في التطبيق عند البناء التالي:

| الصوت | اسم الملف |
|---|---|
| محمد قصاص | `kassas.mp3` |
| رعد الكردي | `kurdi.mp3` |
| أذان الحرم المكي | `makkah.mp3` |
| أذان المسجد النبوي | `madinah.mp3` |

- ⚠️ **حقوق التسجيل**: لا تضف تسجيلاً إلا بإذن صاحبه أو برخصة تسمح بإعادة نشره داخل تطبيق.
- **الصيغة**: يُفضَّل MP3 أحادي القناة بمعدل 64 كيلوبت/ثانية (حجم الأذان الكامل نحو ١٫٥ ميغابايت).
- **التأكد من النص**: استمع إلى التسجيل كاملاً قبل رفعه، وتأكد أنه أذان صحيح كامل.
- يُستخدم الصوت نفسه للإشعار (من `res/raw`) وللمعاينة داخل التطبيق.
