# سكينة 🌙 رفيقك الروحي اليومي

تطبيق أذكار عربي بالكامل (RTL)، خفيف ويعمل **بدون إنترنت**، لأندرويد ٨ فما فوق وللمتصفح.

## التبويبات
1. **الرئيسية**: سماء تتغيّر مع وقت اليوم، والتاريخ الهجري والميلادي، ومواقيت الصلاة مع عدّ تنازلي، و«بماذا يشعر قلبك الآن؟» (٨ حالات)، وبطاقات: وردك الآن، وورد القرآن، وآية اليوم، وحديث اليوم، والمسبحة، واسم اليوم، وأيام الالتزام.
2. **القرآن الكريم**: المصحف كاملاً بالرسم العثماني (٦٠٤ صفحات على تقسيم مصحف المدينة). فيه فهرس للسور والأجزاء، وعلامات، وبحث بدون تشكيل، وتكبير الخط، وتقليب الصفحات بالسحب. والنص في ملف منفصل لا يُحمَّل إلا عند فتح التبويب.
   - **الختمة**: تختار عدد الصفحات اليومي (٥، ١٠، جزء، جزءان، أو عدداً مخصّصاً)، وتصلك تذكرة يومية بالورد، وتتقدّم الختمة تلقائياً مع القراءة.
3. **الأذكار**: الصباح والمساء، وبعد الصلاة، والنوم، والاستيقاظ، والمواقف اليومية، والأدعية القرآنية والنبوية، والرقية، والمفضلة، وأذكاري الخاصة. فيها وضعا التركيز والقائمة.
4. **المسبحة**: ٨ تسبيحات، وأهداف ٣٣ أو ١٠٠ أو ١٠٠٠ أو مفتوح، ووضع التنفس التسبيحي.
5. **المزيد**: رحلتي (الالتزام، والواحة، والمناسبات)، والتذكيرات، وأسماء الله الحسنى، وبوصلة القبلة، والإعدادات، وما الجديد، والتحقق من التحديثات، ومشاركة التطبيق، وحول التطبيق.

### التذكيرات
- أذكار الصباح والمساء والنوم، ودخول وقت كل صلاة.
- تذكيرات جاهزة: صيام الاثنين والخميس، والأيام البيض، والأيام الفاضلة (تاسوعاء وعاشوراء، والعشر من ذي الحجة، وعرفة، والعشر الأواخر، وست شوال)، وسورة الكهف، والصلاة على النبي ﷺ يوم الجمعة، وقيام الليل، والضحى.
- تذكير مخصّص: يومي، أو في أيام محددة من الأسبوع، أو مرة واحدة.
- تذكيرات الصيام في الليلة السابقة أو صباح اليوم نفسه، وما يعتمد على التقويم الهجري يتبع تعديل التاريخ في الإعدادات.

## دقة النصوص
- **القرآن**: نص مشروع [Tanzil](https://tanzil.net) المُدقَّق (`data/tanzil`)، يُستخدم كما هو دون أي تعديل، وفق رخصة CC BY 3.0.
- **الاختبارات** (`tests/accuracy.test.mjs`):
  - كل مقطع قرآني في الأذكار والأدعية يُطابَق حرفاً بحرف مع المصحف، ومع اسم السورة ورقم الآية المذكورين.
  - كل ذكر من أذكار اليوم والليلة يُطابَق مع نص «حصن المسلم» (`tests/fixtures/hisn-muslim.json` من hisnmuslim.com)، وكذلك أعداد التكرار.
- أي تعديل مستقبلي على النصوص يُفشل البناء إن خالف المصدر.

## التحديثات
- يقرأ التطبيق ملف `version.json` من المستودع مرة يومياً، فإن وجد إصداراً أحدث نبّه المستخدم.
- عند صدور إصدار جديد:
  1. ارفع `VERSION` و`VERSION_CODE` في `src/version.js`، والقيم نفسها في `android/app/build.gradle` و`package.json` و`version.json`.
  2. أضف ملاحظات الإصدار في `src/data/changelog.js`.
  3. ارفع وسماً بالأمر `git tag v1.2.0 && git push --tags`، فيُنشأ إصدار على GitHub ومعه ملف التثبيت.
- ⚠️ ليعمل التحقق من التحديثات عند المستخدمين يجب أن يكون الملف `version.json` وصفحة الإصدارات متاحَين للعموم، أي أن يكون المستودع عاماً، أو يُنقل الملف إلى مستودع عام.

## البنية التقنية
- واجهة HTML/CSS/JavaScript بلا إطار عمل، تُجمَّع بـ esbuild بصيغة تعمل على WebView أندرويد ٨.
- **Capacitor 8** لأندرويد، مع الإضافات: التنبيهات المحلية، والاهتزاز، والموقع، والمشاركة، والملفات، وشريط الحالة.
- المواقيت تُحسب فلكياً على الجهاز (`src/prayer.js`)، وتُختبر مقابل مكتبة `adhan` المرجعية بفارق لا يتجاوز دقيقتين.
- التاريخ الهجري بتقويم أم القرى عبر `Intl`، مع بديل حسابي، وتعديل يدوي بين −٢ و+٢ يوم.
- كل البيانات في `localStorage` على الجهاز، دون أي اتصال خارجي.
- الخطوط (IBM Plex Sans Arabic وAmiri) مدمجة داخل التطبيق.

## الأوامر
```bash
npm install
npm test            # اختبارات الوحدة ودقة النصوص
npm run test:e2e    # اختبار الواجهة في Chromium
npm run serve       # تشغيل نسخة الويب على http://localhost:8090
npm run apk         # بناء APK محلياً (يتطلب Android SDK)
```

## بناء APK على GitHub
مع كل رفع يبني GitHub التطبيق تلقائياً. تجده في **Actions ← «بناء تطبيق أندرويد» ← Artifacts ← `sakina-apk`**.

لنسخة موقّعة صالحة للنشر، أضف السرّين `SAKINA_KEYSTORE_BASE64` و`SAKINA_KEYSTORE_PASSWORD` في إعدادات المستودع. مفتاح التوقيع لا يُرفع إلى المستودع أبداً.
